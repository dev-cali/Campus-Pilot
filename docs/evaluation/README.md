# CampusPilot AI Retrieval Evaluation Evidence

## Purpose

This directory preserves historical evaluation datasets,
diagnostics, and results produced during the development
of CampusPilot's retrieval-augmented generation system.

## Evaluation coverage

- Phase 3 baseline retrieval evaluation
- Phase 4 retrieval improvements
- Phase 4.1 generalization testing
- Phase 4.2 ablation and validation
- Phase 4.3 corrected and original evaluations
- Phase 4.4 final retrieval validation
- Evidence completeness and relevance
- Retrieval diagnostics and regression analysis

## Interpretation

- These are historical development artifacts.
- Original and corrected evaluations are retained for transparency.
- Intermediate and unsuccessful experiments are preserved.
- Results from different datasets are not directly comparable.
- Historical results do not independently establish current production accuracy.
- Pinecone integration is evaluated separately.
- Original evaluation values have been preserved.
